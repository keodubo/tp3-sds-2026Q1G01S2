# Source: Guia Presentaciones

**File**: [GuiaPresentaciones.pdf](../raw/Guias%20de%20Formato/GuiaPresentaciones.pdf)  
**Date Ingested**: 2026-04-13

## Summary
This guide is the operational reference for slide structure and oral delivery. It emphasizes a coherent section sequence, concise slides, explicit observable definitions, and conclusions backed only by results actually shown.

## Key Takeaways
- The TP statement has higher priority than generic guides.
- Slides should not contain long paragraphs.
- The suggested section order is introduction, implementation, simulations, results, and conclusions.
- Animations in the submitted PDF must appear as still frames plus explicit links.
- Observable definitions and averaging procedures must be explained mathematically.
- Conclusions must be restricted to evidence shown in results.
